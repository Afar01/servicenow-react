# ServiceNow System — React + TypeScript

A full-featured **IT Service Management (ITSM)** application built with React and TypeScript, replicating core ServiceNow functionality.

## 🚀 Live Features

- **Incident Management** — Create, track and resolve IT incidents with SLA monitoring
- **Service Requests** — Submit requests with manager approval workflow
- **Work Notes** — Collaborative timestamped notes on every record
- **Admin Dashboard** — Role-based access control with manager-only view
- **Search & Filter** — Real-time search and state/priority filtering

## 🖥️ Screens

| Screen | Description |
|--------|-------------|
| Dashboard | Stat cards + recent incidents |
| Incidents | Full list with search and filter |
| Incident Detail | View, update state, work notes, resolve |
| New Incident | Form with auto INC number generation |
| Requests | List with approval status badges |
| New Request | Form with auto REQ number generation |
| Request Detail | Approve/Reject workflow + work notes |
| Admin | Manager dashboard with RBAC toggle |

## 🛠️ Tech Stack

- **React 18** + **TypeScript** — Frontend
- **Vite** — Build tool
- **React Router v6** — Client-side routing
- **Tailwind CSS** — Styling
- **Lucide React** — Icons
- **SharePoint REST API** — Backend (Microsoft 365)
